# 🧠 Week 1 — Machine Learning Fundamentals

This week focused on understanding the **fundamentals of Machine Learning**, exploring datasets, and implementing basic regression and classification models using Python and popular ML libraries.

---

## 🧠 Concepts

* 🤖 What is Machine Learning?
* 📊 Types of Machine Learning:

  * Supervised Learning
  * Unsupervised Learning
* 🔄 Machine Learning Workflow:

  * Problem Definition → Data Collection → Preprocessing → Model Training → Evaluation → Deployment
* ⚖️ Bias-Variance Tradeoff
* 📊 Exploratory Data Analysis (EDA)
* 📉 Gradient Descent:

  * Batch Gradient Descent
  * Stochastic Gradient Descent (SGD)
  * Mini-Batch Gradient Descent
* 🎯 Overfitting vs Underfitting
* 📏 Evaluation Metrics:

  * Accuracy
  * Precision
  * Recall
  * F1-Score
  * MSE
  * R²
